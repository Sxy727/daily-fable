# 开发日志说明

本目录记录项目每天的开发进展。每天（有开发活动的日子）自动创建/更新一个日志文件，命名格式 `YYYY-MM-DD.md`。

## 更新规则

- 每次开发会话结束时，由 Claude 自动创建/更新当日日志
- 同一天多次开发，更新同一个文件（"已完成"保留全量记录）
- 格式固定为四段：已完成 / 待办 / 遇到的问题 / 下次计划

## 日志模板

```markdown
# 开发日志 — YYYY-MM-DD

## 已完成
- 事项 1
- 事项 2

## 待办
- 事项 A
- 事项 B

## 遇到的问题
- 问题描述及解决方案

## 下次计划
- 下一步要做什么
```
