## 遇到的问题
- 网页文件原在 app/ 子目录，GitHub Pages 根目录发布会导致读不到 content/ —— 解决：先更新 tech-spec 目录结构，再把网页文件移至仓库根目录
- 用户反馈页面未显示文字——排查出两个原因并解决：
  1. GitHub Pages 默认的 Jekyll 处理把 content/*.md 当成"未来日期"的文章过滤（返回 404）→ 添加 .nojekyll 禁用 Jekyll
  2. 解析器两处小 bug（隐喻解释首字被截断、故事与概念间的 --- 分隔线被误当正文段落）→ 修复并加入 CRLF 换行符兼容
- 本地 Windows 文件是 CRLF 换行、线上是 LF，导致本地测试与线上行为不一致 → 用 Node 模拟手机浏览器拉取线上文件做端到端验证，线上全流程通过
- 用户反馈调整：历史文章从页面底部移到顶部（日期下方），做成可折叠列表（默认收起，点击展开，选完自动收起）——需求与设计文档已同步更新
- 生成脚本新增日期参数（`generate.py YYYY-MM-DD`）支持补跑指定日期；GitHub 手动运行新增日期输入框，密钥不出 GitHub
