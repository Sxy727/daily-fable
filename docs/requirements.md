# 开发需求 — 每日寓言

> 版本：v1.0　创建：2026-08-28　状态：已确认（用户确认于 2026-08-28）

## 1. 项目背景

用户是编程新手，希望拥有一款运行在手机上的知识软件：每天由 AI 生成一篇"寓言式"文章，围绕一个研究生水平的概念，以讲故事的方式间接讲清概念，让读者在故事结尾恍然大悟。

## 2. 用户画像

- 不懂代码的产品使用者（手机用户）
- 对知识有好奇心，希望每天轻松学到一点"高级概念"
- 偏好简约、精致、有质感的阅读体验

## 3. 核心功能

### 3.1 每日文章展示（核心）
- 每天展示一篇 AI 生成的文章
- 页面显著位置显示当天日期（如"2026年8月28日 · 星期五"）

### 3.2 文章内容结构（固定四段式）
文章必须按以下结构生成：
1. **故事**：一篇寓言，用间接方式讲清某个研究生水平的概念；不要一开始说答案，尽量到故事快结束时才让人意识到讲的是什么概念
2. **概念揭示**：故事结束后揭示今天讲的概念
3. **概念解释**：用通俗语言解释这个概念
4. **隐喻对应**：说明故事里的隐喻分别对应概念的什么部分

### 3.3 历史文章浏览
- 可查看过往每一天的文章
- 历史文章入口位于页面顶部（日期下方），默认收起，点击展开列表（按日期倒序）
- 点击某天 → 切换到该日文章，列表自动收起

## 4. 内容生成规则

### 4.1 用户提供的原始提示词（必须逐字保留）
> 请你从某个领域里，选择一个研究生水平的概念。然后写一个寓言故事，用间接的方式把这个概念讲清楚。不要一开始就说答案，尽量到故事快结束的时候，才让人意识到原来讲的是这个概念。故事结束后，再解释这个概念，以及故事里的隐喻分别对应什么。

### 4.2 领域选择
- 每天从领域池中随机选一个
- 领域池：数学、物理、哲学、经济学、心理学、计算机科学、生物学、语言学（可在 tech-spec.md 中调整）
- 随机选取时避免与近 7 天重复

### 4.3 语言
- 文章全部使用中文

## 5. 非功能需求

| 需求 | 说明 |
|------|------|
| 简约精致 | 页面设计克制、有质感，阅读体验舒适（见 design-spec.md） |
| 稳定可靠 | 每日定时生成，不依赖人工干预 |
| 低成本 | AI 调用约几分钱/天，托管免费 |
| 免维护 | 无服务器、无数据库，内容静态存储 |
| 安全 | API 密钥不暴露给任何前端代码 |
| 手机优先 | 页面按手机屏幕设计（约 375–430px 宽） |

## 6. 约束条件

1. 用户不懂代码 → 自动化流程配置好后不需用户操作
2. 不开发原生 App / 小程序（已确认选择 PWA 网页）
3. 不过度设计：不做登录、评论、点赞、推送等额外功能（后续有需要再加）
4. 每个开发阶段完成后需用户验收，确认后才进入下一阶段

## 7. 验收标准（总目标）

- 手机打开网址（或主屏幕图标）即可阅读当天文章
- 每天文章自动更新，无需人工操作
- 历史文章可随时回看
