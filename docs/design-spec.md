# 设计规范 — 每日寓言

> 版本：v1.0　创建：2026-08-28

## 1. 设计理念

**简约精致、如读一本书。**

- 页面像一页安静的纸，把注意力留给文字
- 克制：颜色少、元素少、装饰少
- 精致：字体、间距、排版讲究，有"质感"而非"简陋"

## 2. 配色

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#F7F4EE` | 米白宣纸色，温暖安静 |
| 主文字 | `#2F2B26` | 深墨色，阅读舒适 |
| 次要文字 | `#8B8578` | 日期、标签、辅助信息 |
| 强调色 | `#A64B2A` | 赭红，仅用于日期、分隔线、小点缀 |
| 卡片/分隔线 | `#E5DFD3` | 浅色分隔 |

**原则**：强调色每屏出现不超过 2 处；不使用渐变、阴影、复杂动画（微妙的淡入除外）。

## 3. 字体

| 场景 | 字体 | 说明 |
|------|------|------|
| 标题/概念名 | `"Songti SC", "Noto Serif SC", serif` | 宋体系衬线，有书卷气 |
| 正文 | `"PingFang SC", "Microsoft YaHei", sans-serif` | 手机上清晰易读 |
| 日期 | 同正文，较小字号 + 字距放宽 | 精致感 |

## 4. 页面结构（手机优先，宽约 375–430px）

```
┌──────────────────────────┐
│   2026年8月28日 · 星期五    │  ← 顶部日期（次要色，居中）
│      ─── 赭红短分隔线 ───    │
│        历史文章 ▾           │  ← 折叠入口，点击展开列表（默认收起）
│    8月27日 · 生物学 · …     │
│         寓言标题            │  ← 衬线大标题（居中）
│       领域 · 概念标签        │  ← 小字标签
│                            │
│      （寓言故事正文）        │  ← 大段文字，行高 1.9
│                            │
│      ───── · · · ─────      │  ← 装饰分隔（揭晓答案前）
│     「今天讲的概念」         │  ← 概念揭示（衬线、强调）
│      （概念解释）            │
│      （隐喻对应）            │
└──────────────────────────┘
```

> 历史文章列表放在顶部：方便随时切换日期；默认收起，避免文章多了把正文顶下去。

## 5. 排版规范

| 项目 | 规范 |
|------|------|
| 页面左右边距 | 24px |
| 正文字号 | 16px（行高 1.9） |
| 标题字号 | 26px |
| 日期字号 | 13px，字距 2px |
| 段落间距 | 24px |
| 段落首行缩进 | 2em（故事正文） |
| 最大内容宽度 | 560px（手机满宽，平板居中） |

## 6. 交互规范

- 打开页面默认展示**最新**的文章（当天已生成则为当天）
- 历史列表默认收起，点击「历史文章」展开/收起
- 点击历史列表条目 → 切换到该日文章，列表自动收起，顶部出现「回到今天」按钮
- 过渡：内容切换 200ms 淡入，无其他动画
